> Sorry, I can't make it — I'm stuck in a meeting about why we have too many meetings. It's going great.

**Character count:** 102 (limit: 200)

## The idea

The excuse turns the meeting itself into the alibi: you're not skipping work, you're trapped in a meeting *about* the meeting problem — and the kicker, "It's going great," lands the irony that the anti-meeting meeting is itself running long and presumably spawning more meetings. It's a fresh, self-referential angle (no bad wifi, no cat, no dentist) that any office worker recognises instantly.

## How to run

```sh
node main.ts
```

Writes the line byte-exact (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`). Node 22, no dependencies, no network.
